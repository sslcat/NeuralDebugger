# Hybrid experiment protocol

I compare the standalone base, the epoch-3 adapter, a display-only hybrid and a conditioned hybrid. I keep the base model as the product default. My primary endpoint is the fraction of the 24 independent programs passing every behavioral probe. I report the 12 legacy programs separately. Both suites have results from earlier experiments, so this is a prospective comparison on known benchmarks. I make all new prompt and routing decisions using validation.

The adapter classifier generates only the category value after a fixed JSON prefix. It stops at the closing quote or 16 generated tokens. I compare a category-specific instruction with the original supervised instruction on every validation case. I select the most correct, then the most parseable, breaking ties in favor of the original prompt. I exercise both repair paths on every fourth validation row starting at zero. I retain both architectures for the final measurement irrespective of their validation repair scores.

The display-only hybrid attaches the adapter category to an otherwise ordinary base diagnosis. The conditioned hybrid also passes the category as a fallible JSON hint to the repair model. The repair stage gets the complete original code and failure. Invalid classifier output falls back to base classification and repair. A hint that exceeds the input budget is omitted. I use a single frozen backbone per request and temporarily disable LoRA for repair. Every repair uses greedy decoding with the original 384-token cap. I freeze implementation and configuration hashes before the held-out runs.

I warm each arm once on the same validation case. End-to-end inference latency includes both decodes, adapter switching and final schema parsing, with GPU synchronization. Offline behavioral scoring and model startup are outside the timer. I measure peak PyTorch allocated and reserved memory per request after warm-up. Each arm runs in a separate process on the same local card. Sequential runs can experience different background load.

I score raw model prose before the app's truthiness correction. I reuse the previously masked semantic scores only for identical prose on the same case. I mask model identities and patch outcomes for newly worded answers and use the same 0–2 cause and explanation rubric. Classification accuracy in the final response and accuracy of the classifier stage alone have separate denominators when repairs fail to parse. I retain all raw responses, failed cases and classifier mistakes. Paired confidence intervals resample complete programs within each suite.
