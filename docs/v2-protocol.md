# Local paired trial protocol

I reserve two distinct evaluation populations. The 12 legacy functions have been examined previously. I authored the new 24-function suite directly from behavioral contracts, failure mechanisms and edge cases before collecting either model's predictions. I use its independent programs for the primary comparison. All inferences see the original greedy v1 debugging prompt, the buggy code and a concrete observation. Both arms use the identical local GPU, precision, token cap, parser, warm-up, ordering, WASI interpreter and behavioral checks. I store raw generation separately from any app-level factual correction.

I select the adapter solely by lowest validation loss across three epochs of the frozen LoRA configuration. I cap the training subprocess at 900 seconds and each evaluation subprocess at 2,400 seconds. Training reads only the development partitions. I record whole-card utilization and memory once per second and process-specific peak tensor allocation in the training log.

For each set I report whole-program repair, individual probe pass rate, exact error class, unusable response rate and median warmed inference latency. Malformed schema, invalid Python, or missing function makes a response unusable. A plausible program that fails behavior is a failed repair. I retain all failures. Wilson 95% intervals apply to binary program outcomes. Paired intervals resample whole programs, preserving the correspondence between models and the clustering of inputs within each program.

I score diagnostic prose with model identities masked and without patch results. Cause earns 2 for the correct specific mechanism, 1 for a relevant but incomplete symptom or a materially qualified diagnosis, and 0 for a missing or incorrect diagnosis. Explanation earns 2 for a factually correct repair rationale tied to that mechanism, 1 for a partially useful explanation, and 0 for a materially false or missing rationale. A parser failure earns zero. A separate Codex assessment reads every answer with the case and reference. This is one AI-assisted review, with no independent human adjudication. A correct patch cannot compensate for a materially false explanation. Lexical measurements from the historical benchmark remain labeled proxies.

The primary outcome is the change in the fraction of independent programs passing every probe. I report direction and uncertainty even when point estimates disagree across metrics. The legacy set, individual categories and semantic scores are secondary. No prompt tuning, decoding retries, or test-based epoch selection is part of this protocol.


## Interpretation of the completed run

I observed 3 newly repaired and 7 newly broken independent programs. The adapter repaired the optional-alias lookup, comment-prefix extraction and final partial chunk. It lost working repairs for the seat offset, suffix-method call, default history list, interval guard, filename extension, sign mapping and missing-marker slice. Both arms failed width-padding. The full case report includes successes, shared failures and regressions.

The independent classification gain was concentrated in WrongResult (0/13 to 12/13). That target accounts for 89/118 training examples. Several adapter answers suggested a familiar arithmetic or comparison edit unrelated to the bug, including multiplication for a row-unpacking error. I suspect the class balance and repeated mutation phrasing encouraged those shortcuts. This run cannot isolate their causal effect. Training loss decreased, but held-out patch and prose scores also decreased. I retained the base model for the workbench.

The matched decoding settings allow latency comparison for these outputs. Other software used this workstation, and the whole-card utilization samples include that load. Timing does not establish a hardware-independent throughput increase. The paired percentile intervals describe resampling these programs. The masked reviewer could sometimes infer the arm from its writing style. The scores show rubric agreement with one reviewer; inter-rater reliability remains unmeasured.
